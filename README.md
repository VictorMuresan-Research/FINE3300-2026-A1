# FINE3300 Assignment #1 - Fall 2026
## FINE 3300 - Python For Finance Professionals

This repository contains two Python projects that convert between USD and CAD using exchange rate data from the Bank of Canada:
 1. **USD/CAD Exchange Rate Calculator** - Coded Without AI
 2. **AI-Generated Exchange Rate Calculator** - Vibe Coded with ChatGPT-6 Luna 

Both programs read the latest available USD/CAD exchange rate from the provided CSV file, prompt the user for an amount and the currencies to convert from and to, and display the converted amount.
